# Course Platform

A simple responsive **Course Platform website** built using **HTML, CSS, and Bootstrap**.

## 📌 About The Project

This project is a simple educational website that represents an online course platform.

The website includes a navigation bar, hero section, courses/content sections, skills, and other website sections designed using Bootstrap components and custom styling.

The main goal of the project is to practice building a responsive website and using Bootstrap to create a clean and organized user interface.

## 🛠️ Technologies Used

* HTML5
* CSS3
* Bootstrap 5
* JavaScript
* Font Awesome

## ✨ Features

* Responsive navigation bar
* Bootstrap Navbar
* Responsive layout
* Hero section
* Course sections
* Skills section
* Cards for displaying content
* Buttons and Bootstrap components
* Custom styling
* Responsive design for different screen sizes
* Mobile-friendly navigation

## 🚀 How To Run The Project

1. Download or clone the project.
2. Open the project folder in Visual Studio Code.
3. Open `index.html`.
4. Run the file using **Live Server** or open it directly in your browser.

## 🎨 Design

The website uses Bootstrap components together with custom CSS to create a simple and responsive design.

Bootstrap is mainly used for:

* Navbar
* Buttons
* Containers
* Responsive layout
* Cards
* Spacing and utilities

Custom CSS is used to customize the colors, sizes, spacing, and overall appearance of the website.

## 📱 Responsive Design

The website is designed to work on different screen sizes, including:

* 💻 Desktop
* 📱 Mobile
* 📱 Tablet

Bootstrap responsive classes are used to make the layout adapt to different devices.
